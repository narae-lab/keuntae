⚠️ 최종 확인

마감 전 점검 화면 안내

이 화면의 데이터가 최종 급여에 그대로 반영됩니다.
마감 전 아래 4개 항목을 반드시 모두 확인해 주세요.
경로: e-HR → 결재용 → 근태 → 일근무시간관리 → 근무일 설정 후 '조회' 클릭
1. '근태' 항목 확인
신청한 휴가가 정상 반영되었는지 확인
2. 근무 시간 확인
정상, 연장, 야간, 휴일, 휴일연장, 휴일야간 항목 정상 반영 여부 확인
3. 지각/조퇴 직원 확인
지각/조퇴 칸에만 입력 / 차감시간 칸에는 절대 같이 입력하지 마세요 (이중 차감)
차감시간 칸은 다이닝 매장만 사용합니다
4. 당월 휴무일수 부여 확인
인별로 조회하여 off + D코드 합산 숫자 확인 필수!

⚠️ 근태 관리 유의사항

1.임신기/육아기 단축근무자는 연장, 야간, 휴일 근무 절대 불가
2.현장실습생은 연장, 야간, 휴일 근무 절대 불가
주차별 근무일정에 맞춰 근무 편성 必
3.파트타이머는 원칙적으로 휴일근로, 연장근로 발생 불가
부득이 발생한 경우 HR팀 업무연락 상신 必
4.휴직 전 연차 소진 시, 연차 사용일자도 재직일자이므로 해당 기간 휴무 부여 필요
5.휴점 매장 직원이 타 매장 지원근무 시, 개인 휴가일자 및 off 일자에도 지원근무지 등록 必
★ 마감 최종 확인
'일근무시간 조회'에서 OFF 일수 + 휴일근로(D) = 당월 휴무일수 9일과 동일하게 적용되었는지 반드시 확인해 주시기 바랍니다.
